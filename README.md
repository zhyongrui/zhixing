# 知行

一张有故事的中国地图。现在先开发原生 iOS 版；后续 Android、Web 共用同一套地点、视频链接、账号和足迹服务。

## 仓库结构

```text
apps/
  ios/       SwiftUI + MapKit；当前正在开发
```

后续按实际开发进度加入 `apps/android`（Kotlin + Jetpack Compose）、`apps/web`（Web 前端）和 `apps/api`（统一服务端）。跨端共享的数据契约放在 `packages/contracts`，设计资源放在 `design/`；这些目录等出现真实内容时再创建。各客户端保留原生 UI，避免为了共享代码牺牲平台体验。

## 当前功能

- 「知」地图只显示有视频链接的地点，点击地点查看关联链接。
- 「行」地图只显示自己的足迹，可选择地点并记录到访日期和一句话；新足迹默认私密。
- 邮箱注册、登录和密码找回。

iOS 构建步骤见 [apps/ios/README.md](apps/ios/README.md)。

## 多端约定

- API 是地点、链接、账号和足迹的唯一数据源；客户端不各自维护内容库。
- 地点使用稳定 ID；地图坐标、层级和视频链接格式由 API 定义。
- 新端接入前先明确 API 契约与鉴权方式，再实现各端界面。
- 生产地址、密钥和签名材料只放本地或部署环境，不进入 Git。

当前服务端代码仍在已有项目中；迁入本仓库需要单独处理部署与数据迁移，避免影响正在使用的服务。
